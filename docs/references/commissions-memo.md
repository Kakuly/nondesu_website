## サイトへの載せ方（ガイド）

### ライブページに載せる（要約）

- 受付状況（◯ → 「受付中」など短い表示）
- 連絡先（X DM / メール）
- 支払い方法（3種）
- 10% off 条件（目立ちすぎない1行）
- カテゴリ見出し ＋ 代表料金・納期の目安（箇条書き）
- 「お見積もりのみ・該当外も相談可」の一文
- 受付の流れ・NG例（既存ページの骨格を維持）

### メモのみ・後日検討

- イラスト A–D の料金表と参照画像
- 各カテゴリ末尾の ※ 注記全文（商用・個人/企業・変動条件）
- 「セリフ・少量声入れ無料」など細かい例外条項（FAQ 化向き）
- lit.link 特有の装飾記号（⟡.·）の多用

### トーン

- かわいさは残しつつ、公式サイトは **読みやすさ優先**
- 絵文字・記号は見出しやバッジ程度に抑える
- 料金は「〜」表記のまま、変動がある旨は1行でまとめる

### フォーム連携

- 依頼種別: ボーカル / 作詞 / 映像 / イラスト / その他
- 連絡先プレースホルダ: `nondesu0816@gmail.com / @_Non_desu_`
- API 宛先: `CONTACT_EMAIL=nondesu0816@gmail.com`
